Personal Portfolio Website

About the Project

A responsive personal portfolio website built using HTML5 and CSS3 as part of my HTML & CSS Internship Project. It showcases my introduction, education, technical skills, projects, and contact information.

Features

- Responsive design for desktop and mobile devices
- Home and About Me sections
- Technical Skills section
- Projects showcase
- Contact information and profile links
- Clean navigation and modern UI
- CSS hover effects and responsive layouts

Technologies Used

- HTML5
- CSS3
- Flexbox / CSS Grid
- Media Queries

Project Structure

Portfolio-Website/
├── index.html
├── style.css
├── images/
└── screenshots/

How to Run

1. Clone or download this repository.
2. Open "index.html" in your web browser.
3. Explore the different sections of the portfolio.
